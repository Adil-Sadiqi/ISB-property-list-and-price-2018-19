# Property Prices in Islamabad 🏡

This repository contains a **data visualization dashboard** that explores property prices, property types, and locations in Islamabad.  
The dashboard provides insights into the real estate market using interactive charts and summary metrics.

## 📊 Features
- **Maximum Price by Location & Property Type**  
  Compare high-value properties such as houses in F-6, F-7, and farmhouses in Bhara, Chirah, etc.

- **Average Price Gauge**  
  Displays the overall average property price across Islamabad.

- **Property Type Distribution**  
  Pie chart showing proportions of Houses, Flats, Upper Portions, Lower Portions, Rooms, Farm Houses, and Penthouses.

- **Bedrooms & Bathrooms Count**  
  Bar chart comparing property types with their respective bedroom and bathroom counts.

- **Minimum Price by Property Type**  
  Highlights entry-level prices for different property categories.

- **Property Count by Location**  
  Shows which areas (e.g., DHA Defense, E-11, G-13, Bahria Town) have the highest property listings.

## 🛠️ Tech Stack
- **Power BI / Tableau / Matplotlib / Seaborn** (depending on your implementation)
- **Python / Pandas** for data preprocessing
- **CSV/Excel dataset** of Islamabad property listings
